# Contributing

Thank you for helping improve Libre LUCI.

## Before opening an issue

- Search existing issues first.
- Use the bug form for reproducible defects and the feature form for proposed
  behavior.
- Remove credentials, private IP addresses, serial numbers, tokens, and unrelated
  personal data from logs or packet captures.
- Report suspected vulnerabilities privately as described in `SECURITY.md`.

## Planning workflow

1. Create or select a GitHub issue with clear acceptance criteria.
2. Confirm that the issue links the relevant requirement identifiers.
3. Discuss unresolved scope or protocol assumptions in the issue.
4. Open a focused pull request and link the issue with `Closes #<number>`.

Changes to planned behavior should update `docs/requirements.md`.
