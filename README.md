# Libre LUCI for Home Assistant

A planned Home Assistant custom integration for compatible Libre Wireless streamers
using the local LUCI protocol.

## Project status

The project is currently in the requirements and planning phase. No supported
integration release exists yet.

See the [requirements](docs/requirements.md) and
[GitHub Project](https://github.com/users/vessyna/projects/1) for scope and progress.

Please use [GitHub Issues](https://github.com/vessyna/ha-libre-luci/issues) for
actionable requirements, questions, and future defects. Security reports should
follow [SECURITY.md](SECURITY.md).
